# DevRecall
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
User-requested migration: React with Next.js App Router frontend, Express.js on Node.js backend, SQLite, and configurable local Ollama inference. Application code is JavaScript; Python and Vite are no longer required.
## Users and purpose
Open-source maintainers, new contributors, and hackathon evaluators recover technical decisions and rejected alternatives from public discussions. Evaluation uses discussion text without supplying the final PEP.
## Operating context
Local application with public discussion paste, structured messages, optional public GitHub import, source inspection, keyword search and grounded questions.
## Constraints
Never fabricate decisions, rationale, authors, quotations or model execution. Unresolved outcomes stay uncertain. Exact quote validation establishes source presence, not semantic correctness. Preserve HACKATHON.md and first-commit/feature-branch workflow.
## Brand commitments
DevRecall. Every decision has a reason. Never lose it. User selected a dark workspace and direct implementation in code.
## Evidence on hand
Supplied PRD and existing HACKATHON.md. No model installed at project inspection. Any synthetic fixture must be labeled, and actual model output saved separately.
## Accessibility
Keyboard navigation, readable contrast, labeled fields, responsive laptop and mobile layouts, reduced-motion support.
